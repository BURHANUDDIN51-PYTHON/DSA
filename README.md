# DSA

Python solutions to data structures and algorithms problems, grouped by topic.

## Topics

| Folder | Problems |
| --- | --- |
| `Array/` | Two Sum, Valid Anagram, Valid Palindrome, Valid Sudoku, Top K Frequent Elements, Encode/Decode Strings |
| `Two pointers/` | 3Sum, Container With Most Water, Product of Array Except Self, Trapping Rain Water, Two Integer Sum II |
| `sliding_window/` | Best Time to Buy/Sell Stock, Character Replacement, Longest Consecutive Sequence, Longest Substring, Minimum Window Substring, Permutation in String, Sliding Window Maximum |
| `stack/` | Car Fleet, Daily Temperatures, Evaluate RPN, Largest Rectangle in Histogram, Min Stack, Valid Parentheses |
| `binary_search/` | Binary Search, Koko Eating Bananas, Median of Two Sorted Arrays, Minimum in Rotated Sorted Array, Search in Rotated Array, Search a 2D Matrix, Time-Based Key-Value Store |
| `linkedlist/` | Add Two Numbers, Copy List with Random Pointer, Merge Two Sorted Lists, Remove Nth Node, Reorder List, Reverse Linked List |

## Running a solution

Each file is a standalone script:

```bash
python3 stack/min_stack.py
```
